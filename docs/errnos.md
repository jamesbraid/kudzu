# Error numbers returned by handlers

For each native system call handler and each `syssgi` selector of the 6.5.30 kernels, this page
and its table list the constant error numbers the handler returns itself, and the conditions on the
way to each return. The table is [inventory/errnos.tsv](inventory/errnos.tsv), generated by
`scripts/errno_table.py`. Run `scripts/os_tables.py` first (it writes the handler and selector lists the
script reads), then `tools/re-run python3 scripts/errno_table.py`. The table covers the three 6.5.30
kernels (IP27, IP30, IP35). 6.5.22 is not generated.

## Convention

A handler returns its error number in v0, zero for success. A `syssgi` selector's case code leaves
the value in a register that the common exit of `syssgi` moves into v0 (see [syssgi.md](syssgi.md)).
Zero is success and is left out of the table.

## Method

- A system call handler is read from its entry. A `syssgi` case is read from its own address to the
  end of `syssgi`, so the common exit that the cases branch to is part of the read.
- The first-level callees whose return value a handler passes on are read the same way. Their rows
  have `level` = `callee NAME` (or `callee sub_ADDR` for code with no symbol). Routines below the
  first level are not read.
- Each row is one return path with a nonzero value in v0. `from` is the instruction whose edge enters
  the return block. `condition` lists up to three conditional branches on the way, nearest first,
  each with its text and whether the path took it (`taken`) or fell through (`not taken`). `...`
  marks a walk with more branches above.
- The column `traced` is `direct` for a constant on the path, `merged` for one of a set of constants that reach
  the return together, `not traced` for a value passed through from a callee (the callee's own rows
  give its numbers), and `unknown` when the engine did not resolve the value.
- The column `grade` is `established` when the value was read on the path in the binary, `inferred` for a merged
  value, and `unknown` when it was not resolved.

An `unknown` row is not a negative. It says the engine did not resolve the value at that return.

## Known limits

- The engine keeps at most four distinct values for a register where paths join. A join with more
  incoming values gives `?`. The IP27 `numa_tune` (0xc0000000002852b0) is an example. The fall-through
  into the return at 0xc0000000002852ec has eleven incoming edges. The path from the branch at
  0xc0000000002852e4 sets 22 in its delay slot (0xc0000000002852e8), but the table shows `?` for that
  return. The value 22 is confirmed by reading the disassembly.
- A case code can move a callee's result through a3 rather than v0, and the common exit then reads
  the other register. The IP35 `part_operation` case (selector 195) is an example. Its callee returns
  89, which reaches v0 through a3, but the table shows `?`.
- Values that come from memory, from a stack slot, or from a second-level callee are not traced.
- Indirect calls through a register are not followed.

## Entries

Each entry names what was read by hand against the binary. The generated rows for the same routine are
in the table; where they disagree, the entry gives the reading and says why.

### `syssgi` 7 (SETLED)

- Selector 7 on IP27 (case code at 0xc0000000002331a8 in `6.5.30/unix.IP27`): the case code calls `cap_able` at 0xc0000000002331ac and
  branches to 0xc000000000233834 when its result is zero (0xc0000000002331b4). The code at that target
  jumps to the common exit and sets 1 in a3 in its delay slot (0xc000000000233838; the branch at 0xc0000000002331b4 has a nop
  there), and the common exit copies a3 into v0 (0xc000000000231864). So the return is 1 on that
  path, and the table row has `from` 0xc000000000231850 with the branch as its condition. The other
  path calls `sys_setled` and returns 0. Established.
- Selector 7 on IP35 (case code at 0xc0000000002e1da0 in `6.5.30/unix.IP35`): the same check. The branch at 0xc0000000002e1db4 goes to
  0xc0000000002e39bc when the result is zero, which sets a3 to 1 in its delay slot and jumps to the common
  exit at 0xc0000000002e059c. The return is 1 (table row from 0xc0000000002e059c, merged with the 22
  below). A selector that does not match takes the branch at 0xc0000000002e1da0 to 0xc0000000002e0598,
  where a3 is set from s1, and s1 was set to 22 in that branch's delay slot (0xc0000000002e1da4). So
  the return is 22. Established.

### `syssgi` 195 (PART_OPERATIONS)

- Selector 195 on IP27 (case code at 0xc0000000002323ec in `6.5.30/unix.IP27`): the case code's result is the return value of
  `part_operation` (0xc0000000003c23e4), which returns 89 (its own row in the table is `callee part_operation`,
  `direct`, 89). So the selector returns 89. Established.
- Selector 195 on IP30 (`6.5.30/unix.IP30`, the shared default at 0xa8000000201eba10), which sets 22. Established.
- Selector 195 on IP35 (case code at 0xc0000000002e10e0 in `6.5.30/unix.IP35`): the case calls `part_operation` at 0xc0000000002e10f8.
  Its result goes to a3 in the delay slot of the branch at 0xc0000000002e1100, which jumps to the common
  exit past the instruction that copies s1 into a3. So the return is the callee's 89 on that path, and 22
  on the mismatch path (0xc0000000002e10e4 sets s1 in the delay slot of the branch at 0xc0000000002e10e0).
  The table shows `?` for both (limit 2 above). Established by reading the case code; the table is not
  the source for this entry.

### `syssgi` 218 (NUMA_STATS_GET)

- `numa_stats_get` (`6.5.30/unix.IP27`, 0xc00000000026d748, 192 bytes), reached from the case code at 0xc0000000002322d8:
  - 22 when the path argument is zero (the branch at 0xc00000000026d750 goes to 0xc00000000026d780).
  - 2 when the path lookup (call at 0xc00000000026d768) returns nonzero (the branch at 0xc00000000026d770
    falls through to 0xc00000000026d778, which sets 2).
  - 22 when the node from `master_node_get` is -1 after sign extension from 16 bits (the branch at
    0xc00000000026d7b4 goes to 0xc00000000026d780).
  - 14 when the buffer pointer is zero (the branch at 0xc00000000026d7bc falls through to 0xc00000000026d7c4).
  - 14 when `copyout` (call at 0xc00000000026d7e8) returns nonzero (the branch at 0xc00000000026d7f0 falls
    through to 0xc00000000026d7f8).
  - 0 otherwise (0xc00000000026d804).
  Established. The table's four rows for this routine match.
- `numa_stats_get` (`6.5.30/unix.IP35`, 0xc00000000031c3c0, 192 bytes): the same six paths as IP27, read in the disassembly:
  22 when the path argument is zero (branch at 0xc00000000031c3c8 to 0xc00000000031c3f8); 2 when the path lookup
  (call at 0xc00000000031c3e0) returns nonzero (0xc00000000031c3e8 falls through to the `li v0,2` at 0xc00000000031c3f4);
  22 when the sign-extended 16-bit node returned by the `master_node_get` call (0xc00000000031c408) is -1 (branch at 0xc00000000031c42c); 14 when the buffer pointer is
  zero (0xc00000000031c434 falls through to 0xc00000000031c440); 14 when `copyout` (call at 0xc00000000031c460) returns
  nonzero (0xc00000000031c468 falls through to 0xc00000000031c474); 0 otherwise (0xc00000000031c47c). The table's four rows
  for this routine match. Established.
